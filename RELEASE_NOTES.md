# Warp4D 1.2 Preview 1

A major update to the native Windows 4D NES experience.

- Eleven live styles and all six rotation planes.
- Independent rotation of each projection, automatic cycling, randomization, and fully adjustable opacity.
- Expanded game profiles, improved player/sprite ownership, and better HUD protection.
- Visual profile editing with additive selection, dragging, Undo/Redo, import/export, and Save & Apply.
- GPU rendering improvements, reusable background/overlay storage, and clean gameplay recording.
- New Contra base scenery and Castlevania player/bat layout updates.

Download **Warp4D-1.2.0-preview.1-win-x64.zip**, extract it, and run **Warp4D.exe**. No browser or separate runtime is required. Open your own ROM manually; no ROMs or automatic ROM loading are included.

Existing custom profiles remain in use. Export a backup before replacing one. The optional **Contra-both-base-bosses.warp4d-game.json** asset can be imported through Ctrl+G, then Save & Apply.

This is a preview release. Profile coverage varies by game and scene.

GPL-3.0; native-core source and license notices are included with the release assets.
